버전 2.0 / 2026-09-17 / 1인·8주 기준. [PRD](PRD.md)와 [기술 설계](ARCHITECTURE.md)를 함께 읽는다. `Txx`는 문서의 안정적인 작업 ID이며 GitHub 이슈 번호와 구분한다. 아래 기존 T01~T24 중 CSV·패션·데모 fallback 언급은 v1 기록이며, 현재 구현에는 다음 변경 작업이 우선한다.

## 실행 원칙

P0 24개 작업의 추정은 총 **32인일**, 인터뷰·큐레이션·외부 대기·수정 버퍼 **8일**로 40영업일을 계획한다. 견적이 아닌 초기 가정이며 T01 이후 재산정한다. 고객 관찰·API 심사 달력 기간은 인일에 포함되지 않는다. T24의 작업 완료가 장기 지표 달성을 뜻하지 않는다.

핵심 경로는 T01→T02→T03→T04→T05→T09→T10→T11→T12→T13→T14→검증→파일럿이다. T09는 T08의 트렌드 경로도 필요하다. 1인 개발이므로 의존성이 없는 작업도 자동 병렬 개발로 일정 단축을 가정하지 않는다.

기본 Definition of Done: 관련 PRD 수용 기준 만족, 오류·빈 상태 처리, 필요한 권한·원가·수치 검증, 변경 문서 갱신, 비밀값 미포함. 필수 외부 조건이 미검증이면 기능을 동작한 것으로 표시하지 않는다.
