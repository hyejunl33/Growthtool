# Growth tool VC 소개

## 평가 기준

- 문제의 명확성: 고객이 반복적으로 겪는 비용과 병목이 구체적인가
- 시장성: 초기 고객군이 선명하고 확장 가능한가
- 솔루션·차별화: 기존 템플릿 도구와 다른 핵심 가치가 있는가
- 사업모델: 고객 가치와 과금 방식이 자연스럽게 연결되는가
- GTM: 첫 고객을 확보하고 검증할 현실적인 경로가 있는가
- 실행력·검증: 현재 구현 범위와 검증할 지표가 구체적인가
- 확장성: 데이터 축적이 제품 경쟁력과 B2B 확장으로 이어지는가

## 소개문

**Growth tool은 흩어진 트렌드를 매출로 바꾸는 뷰티 퍼포먼스 마케팅 에이전트입니다.**

뷰티 셀러에게 광고 소재는 한 번 만들고 끝나는 결과물이 아닙니다. 유행과 고객 반응이 빠르게 바뀌고 소재 피로도가 누적되기 때문에 매주 새로운 가설과 배너를 시험해야 합니다. 그러나 소규모 D2C 셀러와 1인 창업가는 트렌드 탐색, 경쟁 광고 분석, 카피 기획, 디자인 제작을 모두 수행할 인력과 시간이 부족합니다. Canva 같은 템플릿 도구는 제작 속도는 높이지만, “지금 무엇을 말해야 전환되는가”까지 답하지 못합니다.

Growth tool은 이 과정을 하나의 실행 흐름으로 연결합니다. 네이버 쇼핑인사이트를 시작으로 TikTok, X 등에서 뷰티 트렌드 신호를 수집하고, 셀러가 입력한 제품 이미지와 상품 정보를 AI가 분석합니다. 이어서 선택한 트렌드와 제품 소구점을 결합해 광고 카피와 A/B 테스트용 배너를 생성합니다. 현재 실제 트렌드 API와 OpenAI 이미지 생성 모델을 연결해, 사용자가 자신의 제품을 넣고 결과물을 만들 수 있는 웹 MVP를 구축하고 있습니다.

차별점은 디자인 생성보다 앞단의 의사결정과 뒷단의 학습까지 자동화한다는 데 있습니다. 어떤 트렌드가 브랜드와 맞는지 판단하고, 제품의 시각적 특징과 구매 이유를 소재에 반영하며, 향후 Meta·TikTok·Google Ads·Moloco 성과 API를 연결해 성과가 떨어지는 소재의 교체 시점까지 제안합니다. 트렌드→기획→생성→성과 데이터가 축적될수록 카테고리와 브랜드별 성공 패턴이 정교해지는 구조입니다.

초기 시장은 소재 교체 빈도가 높은 뷰티 카테고리입니다. 네이버 스마트스토어와 쿠팡의 소규모 셀러 50곳을 대상으로 “상품 URL과 이미지만 주면 트렌드를 반영한 배너 3종을 제작”하는 PoC를 진행해 제작 시간 단축, 실제 집행률, 반복 사용률, ROAS 변화 가능성을 검증합니다. 초기에는 플랫폼이 만든 캠페인에서 전환 매출이 발생할 때만 3~5%를 받는 성과 수수료로 도입 장벽을 낮추고, 이후 여러 브랜드와 광고 계정을 운영하는 대행사·인하우스 팀을 위한 구독형 B2B 솔루션으로 확장합니다.

Growth tool이 만들고자 하는 것은 또 하나의 디자인 툴이 아니라, 작은 셀러도 데이터와 AI를 기반으로 매일 광고 실험을 반복할 수 있는 마케팅 운영체제입니다.
